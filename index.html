shutter-mapper

A personal research tool I'm building for my contributor work. It maps which parts of a city are already covered by Shutterstock editorial video (starting with Amsterdam), so I can plan shoots for the places that aren't.

It uses the Shutterstock API read-only, to search clip metadata. The data stays on my own machine, and no Shutterstock content is redistributed or published.
